# Sweet Charm O' Mine

Transform your firearms experience with **Sweet Charm O' Mine**, a tactical accessories mod built for **Guns Without Roses**.

## What's New in 1.1.0

- **Ammo Belt**: Configure per-gun ammo firing belts and control which ammo type each firearm pulls next.
- **Pocket Ammo Cycling**: Switch bullet pocket ammo with keybinds and see the selected ammo in a clean HUD overlay.
- **Cloth Config Support**: Adjust client options from the mod config screen, including sniper zoom mode and pocket ammo overlay layout.
- **4x Default Scope Zoom**: Sniper scopes now start at 4x zoom by default.

## Sniper Scope System

Experience precise long-range shooting with an advanced scope system:

- **Triple Zoom Modes**: Cycle between 4x, 8x, and off with a single keypress.
- **Smart Equipment Detection**: Requires a sniper rifle and an equipped Sniper Scope.
- **Sneak to Aim**: Activate the selected zoom mode naturally while sneaking.

## Bullet Pocket Storage

Carry more ammunition with the tiered bullet pocket system:

- **5 Material Tiers**: Copper, iron, gold, diamond, and netherite.
- **Up to 45 Slots**: Netherite pockets provide maximum capacity and fire resistance.
- **Curios Integration**: Equip bullet pockets through the Curios slot system.
- **Ammo Selection Overlay**: Quickly preview and cycle stored ammo without opening the pocket.

## Ammo Belt

The **Ammo Belt** adds per-gun ammo sequencing:

- Configure a custom ammo order for each gun.
- Pull matching ammo from your inventory or equipped bullet pocket.
- Set repeated shots per ammo entry for controlled firing patterns.

## Tactical Accessories

Includes **8 combat accessories** that change how you approach firefights:

- Sniper Scope
- Ammo Belt
- Dunlop Pick
- Bullet Shell Charm
- Gunpowder Bag
- Magazine
- Shotgun Shells
- Tobacco Pipe
